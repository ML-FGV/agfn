# Ancestral GFlowNets 

This repository contains the code for AGFN. 


We assume that you have both [R](https://cran.r-project.org/bin/) and [uv](https://docs.astral.sh/uv/getting-started/installation/) installed. 

```
uv venv 
source .venv/bin/activate
uv sync
```

The main experiments can be found at examples/agfn.ipynb and Experiments.ipynb.
